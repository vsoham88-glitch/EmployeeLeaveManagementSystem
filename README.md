# Employee Leave Management System

A web-based Employee Leave Management System developed using PHP and MySQL. It allows employees to apply for leave online while enabling administrators to approve or reject requests efficiently.

## Features
- Employee Login
- Admin Login
- Leave Application
- Leave Approval & Rejection
- Leave History
- Employee Dashboard
- Attendance Management

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Installation
1. Clone the repository.
2. Copy the project to the `htdocs` folder in XAMPP.
3. Import `database.sql` into phpMyAdmin.
4. Start Apache and MySQL.
5. Open `http://localhost/EmployeeLeaveManagementSystem/`.
